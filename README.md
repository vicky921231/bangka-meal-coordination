## 這是在解決什麼問題

艋舺公園長期有多個個人／慈善團體各自獨立發放便當，彼此沒有溝通管道，導致時段撞期、同一批街友一餐拿到數份便當、吃不完的便當被丟棄、公園衛生惡化，團體也難以估算該準備多少份數。

這個 App 是一張**共享的時段登記表**：不強制分配、不阻擋任何人發餐，只讓資訊透明，讓原本互不認識的發餐團體能在同一個畫面上看到彼此的計畫，進而自主錯開時間。

**街友不是這個 App 的使用者**，不需要掃碼、感應卡或任何配合動作。街友人數改由協調管理端定期現場普查更新。

## 兩種角色

| 角色 | 主要畫面 |
|---|---|
| 發餐團體／個人 | 本週時段總覽表（3 時段 × 7 天）→ 點格子登記 → 依最新普查人數得到建議份數 |
| 協調管理端（社企／社工） | 更新街友人數普查、查看本週供需落差清單、導入成效卡片 |

## 份數建議怎麼算

```
建議備量     = 街友人數普查 × 1.1（無條件進位）
建議搭配份數 = 建議備量 − 該時段已登記份數
```

10% 是因應臨時到場、現場分配不均的緩衝。程式中的 `BUFFER` 常數可調整。

時段顏色分級以普查人數為基準：0 份為灰、低於 60% 為黃（份數不足）、60–120% 為綠（適中）、超過 120% 為紅（超量，系統提醒但不阻擋）。

## 未來延伸方向

發餐時段只是起點。同一張協調表可延伸登記物資捐贈與生活服務：捐贈物資（睡袋、衣物、保溫瓶）、物資愛心倉庫，讓善意不只集中在便當、也不再擠在同一個季節。

其中「冬至舞踏奉茶」不只是把物資交出去——一起跳舞、遞上一杯熱茶，看見笑容與手心的溫度，隔閡就在那一刻融化。餐食與物資解決當下的匱乏，面對面的接觸改變的是長期的形象與偏見。
